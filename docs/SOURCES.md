prompts and fictional examples are included in this repository under the
[MIT license](../LICENSE). It does not bundle another agent framework or any
personal project's instructions, conversations, task registry, or credentials.

## Original artwork

- `assets/company-hero.png`: AI-generated editorial illustration, produced for
  this repository with the built-in OpenAI image-generation tool. It depicts
  fictional people and robots and contains no real project data. Prompt brief:
  a wide, warm-ivory architectural miniature with exactly one human owner,
  one robot CTO, and three lead islands with parallel robot workstations;
  forest green and orange accents, soft daylight, no text or brand marks.
  Standard C2PA AI-origin credentials are retained; see [privacy and provenance](PRIVACY.md).
- `assets/organization.svg`: original, editable diagram of the management and
  coordination relationships.
- `assets/parallel.svg`: original scheduling illustration. Its assumptions and
  arithmetic are documented in [EXAMPLES.md](EXAMPLES.md).

The artwork illustrates the operating model. It is not a screenshot of a
running orchestration product or a result of a performance benchmark.
