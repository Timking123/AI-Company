# 工程检查与证据方法

本页给出[工作流3.1.0](../WORKFLOW.md)的按需方法。项目契约决定数据和必需门，以下对象与示例保持虚构。

## 正常入口和契约

关联WF04、WF05、WF06、WF20。

- 找实际写入、序列化、读取和请求入口，覆盖真实版本及参数。直接构造数据模型只能验证模型层，持久化封套、认证和恢复字段还有自己的消费者。
- 分清产品安装或运行源与生成、控制、核收它的维护源。固定本次实际组合，用合法正常输入经维护构造入口贯通受影响caller，临时复制或硬编码旧版本不作为正常修复。
- 用真实代码生成安全样本，包含合法对象、空集、合法历史格式、正常临时项和关键错误。临时示例注明未证假设。
- 批前先跑受影响的代表链：准备→实际就绪→正常产物→停止→后继接续，并核本次配置变更能沿正常入口到达消费者。正常产物只能在正常阶段产生，不能反向要求准备阶段已持有它。真实外部门仍按授权与实际窗口执行。
- 请求与响应成对校准，覆盖合法状态集合、非零退出的结构化失败、未执行、部分成功、超时和取消。新字段沿实际接收链验证。
- 正常SDK、模块和工具已有入口时直接复用。mock适合确定性分支和故障注入，真实shell、平台、服务或传输保对应验证。
- Git raw、checkout、打包与部署各取原字节。语义摘要用已有canonical函数，文件摘要来自实际文件，转换有明确依据。

## 独立判定和评测

关联WF07、WF19。

- 关键计分、授权和数据变换的期望来自独立规格或金标。生产映射与测试共用常量时说明共同错误的覆盖缺口。
- 用少量已知错误检验判定器。例如拒绝改成通过、错误主体、契约明确禁止的版本仍被接受或字段被丢弃时，相关检查应失败。配对检查契约支持的合法历史版本仍可正常通过。
- 运行完成、样本成功、评分有效和业务状态分别读取。分母涵盖实际要求的样本，缺失、NA、失败和取消保原含义。
- 模型评委保理由与样本依据，核事实误读和题目前提。质量结论注明候选、数据、模型和不确定性。
- 同源转载和同页多字段的证据独立性有限。原始图像、声音、台词和作品阶段按各自目标验证。

## 最小失败回执

关联WF08、WF12。按诊断目的选择字段，使用现有正常输出入口。

| 发生层 | 通常有用的非敏信息 | 保全边界 |
| --- | --- | --- |
| HTTP/SDK | 请求引用、目标类别、状态、类型/编码、响应字节、可信错误类型/固定码 | 正文和headers私值依授权处理，解析失败仍保已有元信息 |
| 子进程 | 正常入口、native退出、超时/取消原因、stdin完成、双流完整性、所属资源 | writer失败无法独立证明远端未开始，取消另有退出确认 |
| 数据/模型 | 安全固定码、最内层受信源码阶段、可信类型、允许公开的字段位置、读/验数量、部分覆盖 | 不打印ValidationError私input、args或环境，未知字段按敏感性处理；空泛AssertionError不能覆盖已知原因 |
| 资源/收尾 | 对象身份、主因、独立close错误、已释放和未确认部分 | 只核本任务对象及相关状态，无关全局变化另记 |

限额内优先保最初有效原因、有限类型链和计数，并明确截断。收口错误独立记录。原件未采到的事实保持未知，后继解释注明依据。诊断器采到原因只证明诊断完成，原业务失败仍为失败。

## 生命周期、兼容和资源

关联WF09、WF15、WF20。

- 启动到实际就绪、正常请求、停止和释放形成闭环。共享端口和既有实例先识别归属，维护切换沿产品支持的语义。
- 明确可能已发生副作用的位置，重试按幂等和剩余次数执行。预期拒绝有可消费结果，独立只读子项按原任务语义继续。
- 核完整依赖计划和失败后接续条件。初始不存在、创建中和已创建后的路径含义不同，临时目录竞争与稳定根变化分开判断。
- 总期限向子过程传递剩余量。平台启动、流写入、回收和句柄释放按真实能力验证，公开close与物理释放各有证据。
- 计量注明统计根、别名、接口去重、采样时点和覆盖。现有模型存量、临时材料和运行内存分别核算。
- 材料范围按并集与实际物理对象核算，预留、共享缓存与已占用不重复相加。在原硬总域内由原责任人一次合理调剂内部子额，生产窗口和启动次数独立不变。
- 旧数据按正常存储协议理解。模型拒绝不能独立证明损坏，修改、迁移和恢复有对应授权、保全和验证。

## 验证记录

一项可复用记录包含候选或组件组合、正常入口、必要环境与身份、实际命令或调用引用、结果及失败、验证层和复用边界。一名主审负责固定差量，后续检查针对变化与未覆盖风险。方法依据见[研究来源](RESEARCH.md)。
